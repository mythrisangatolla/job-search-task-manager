# Job Search Task Manager

A simple web app to organize a job search. Track applications, follow-ups,
interview prep, networking and skill-building tasks in one place.


## Features

- Add, edit, delete and complete tasks
- Categories: Apply, Follow-up, Interview prep, Networking, Skill building, Resume & portfolio
- Priority levels (High, Medium, Low) and due dates
- Overdue tasks are highlighted in red
- Search by task or company, filter by category or status, and sort
- Progress dashboard showing total, completed and due tasks
- Tasks are saved in the browser using localStorage
- Responsive layout with automatic dark mode

## Built With

- HTML5
- CSS3 (Grid, Flexbox, CSS variables)
- JavaScript (DOM manipulation, localStorage)

## How to Run

1.Download this repository (green **Code** button, then **Download ZIP**) and unzip it.
2. Open `index.html` in your browser.
